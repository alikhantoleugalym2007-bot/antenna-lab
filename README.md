# Антенна зертханасы · Лаборатория антенны

Интерактивная физическая лаборатория: **угловое разрешение параболической антенны** (критерий Рэлея, θ ≈ 1,22 λ/D).
Два языка: қазақша / русский. Дано: D = 0,8 м, f = 3 ГГц → θ ≈ 0,153 рад ≈ 8,74°.

## Структура

```
index.html        разметка
css/style.css     оформление
js/main.js        физика, тексты (kk/ru), отрисовка на canvas
assets/favicon.svg
404.html
```

Сборки нет: чистый HTML/CSS/JS без зависимостей (шрифты — Google Fonts).

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
